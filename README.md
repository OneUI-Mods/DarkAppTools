# Sesame UI Tools

セサミアプリにダークモードを追加する非公式のVectorモジュールです。

- 端末に合わせる・常にダーク・元のライト表示を選択
- 一覧、文字、背景、単色アイコン、ダイアログの配色を調整
- 機器の状態を表す色と写真は維持
- 日本語・英語の設定画面、配色プレビュー、ライセンス一覧

## 対応環境

Android 16〜17とVector API 102、セサミ **3.0.266** が必要です。Android 17の実機で一覧・メニュー・Web画面と、ライト表示／OFF時の復元を確認しています。Android 16は公開APIの共通実装を使用しますが、実機検証は未実施です。未確認のセサミバージョンには変更を適用しません。

## 導入

1. [Releases](https://github.com/OneUI-Mods/SesameUITools/releases)から署名済みrelease APKをインストールします。
2. VectorでSesame UI Toolsを有効にし、対象に「セサミ」を選択します。
3. Sesame UI Toolsでテーマを選びます。
4. セサミの「アプリ情報」で強制停止してから、セサミを開き直します。

更新版が反映されない場合は、Vectorでこのモジュールを一度OFF→ONにし、セサミを開き直してください。

設定や端末のテーマを変更した後も、セサミを終了して開き直してください。端末やSystemUIの再起動は不要です。OFFにして開き直すと元の表示に戻ります。

## 制限とプライバシー

Web画面のダーク表示はAndroid System WebViewとページの対応に依存します。写真、動画、QRコードや独自描画の機器イラストは一律に反転しません。一部の独自描画には明るい部分が残る場合があります。

セサミ本体のAPK・鍵・データは変更しません。この拡張アプリに通信権限はなく、解錠・施錠などの機器操作を追加・変更しません。CANDY HOUSEとは関係のない非公式プロジェクトです。
