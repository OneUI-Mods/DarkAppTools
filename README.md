# Dark App Tools

セサミとpovoにダークモードを追加するVectorモジュールです。アプリごとに配色を選べます。

## できること

- アプリごとにON／OFFを切り替え
- 「端末に合わせる」「常にダーク」「元のライト表示」を選択
- 背景、文字、単色アイコン、確認済みの付属UIアイコンをダーク配色へ調整
- セサミの機器状態の赤・青緑、povoの黄色など、意味のある色を維持
- セサミの検索欄とその周囲もダーク配色へ統一
- povoのプロフィールを不透明な暗い背景にし、項目の面・白い矢印・住所と支払い方法の鉛筆を見やすく表示
- povoの通知一覧は、スクロール中に新しく出る行も表示前にダーク配色へ調整
- Web画面のダーク表示、日本語・英語、ライト／ダークの設定画面、ライセンス一覧
- 対象アプリごとのクラッシュ保護

写真・動画・広告バナー・QRコードを一律に反転する機能ではありません。機器操作、購入、契約変更などの機能を追加・変更しません。

## 対応環境

Android 16〜17、Vector API 102が必要です。確認済みの対象バージョンだけに適用します。

| アプリ | バージョン |
| --- | --- |
| セサミ | 3.0.266 |
| povo | 1.71.0-JP |

未確認の対象バージョンでは元の表示を維持します。Android 17実機で、両アプリのホーム、povoのトッピング一覧・プロフィール・通知一覧のスクロール、OFF時の元配色への復元を確認しています。Android 16の実機検証は未実施です。Web画面はAndroid System WebViewとページ側の対応にも依存します。

## 導入・更新

1. [Releases](https://github.com/OneUI-Mods/DarkAppTools/releases)から署名済みrelease APKをインストールします。
2. VectorでDark App Toolsを有効にし、対象にセサミ・povoが表示されることを確認します。
3. Dark App Toolsで対象アプリのタブからテーマを選びます。
4. 対象アプリをアプリ情報から強制停止し、開き直します。端末・SystemUIの再起動は不要です。

通常の更新ではモジュールのON／OFFを切り替える必要はありません。設定や端末のテーマを変更した後も、対象アプリを強制停止して開き直してください。

OFFまたは「元のライト表示」を選んで対象アプリを開き直すと、元の配色に戻ります。クラッシュ保護で止まった場合は、対象アプリのタブで保護を解除できます。

## 0.2系・旧Sesame UI Toolsからの移行

0.3.0以降のパッケージ名は`dev.ryuya.darkapps`です。0.2系までの`dev.ryuya.sesameui`とは別アプリになるため、上書き更新ではなく設定の移行が必要です。

1. 新版の署名済みrelease APKをインストールします。旧版はまだ削除しないでください。
2. セサミ・povoそれぞれの有効状態、テーマ、アプリの言語を引き継ぎます。rootとADBを使える場合は、[設定移行の手順](docs/migration.md)にある補助ツールでバックアップと移行・照合を行えます。手動で同じ設定にすることもできます。
3. Vectorで旧パッケージのモジュールを無効にし、新パッケージのDark App Toolsを有効にします。
4. セサミ・povoを強制停止して開き直し、表示とモジュールの状態を確認します。
5. 新版が動くことを確認してから旧パッケージだけをアンインストールします。元のセサミ・povoアプリは引き続き必要です。

通常の0.3系以降の更新では、設定を保持して上書きインストールできます。現在の配布先はこのリポジトリの[Releases](https://github.com/OneUI-Mods/DarkAppTools/releases)です。

## 制限とプライバシー

アプリの全画面・すべての独自描画を網羅するものではありません。写真やWebコンテンツなどにライト表示が残る場合があります。外部のブラウザや別アプリは対象外です。

管理画面に通信権限はありません。保存するのは表示設定だけです。利用状況の送信・広告はありません。CANDY HOUSE・KDDIとは関係のない非公式プロジェクトです。

利用方法はこのREADME、[開発者向けの構成と試験記録](docs/development.md)、[配布手順](docs/releasing.md)を分けています。本体はMIT Licenseです。依存ライブラリの表示はアプリ内「ライセンス」から確認できます。
