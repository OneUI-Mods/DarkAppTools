# 0.3系への設定移行

0.3系は`dev.ryuya.darkapps`です。旧ID`dev.ryuya.sesameui`からは別アプリとして移行します。署名済みAPKだけを使用し、確認が終わるまで旧版を残してください。

## ADBとrootで移す場合

PCにPython 3、ADB、Android SDK Build Tools 37.0.0が必要です。端末で、このPCからのroot実行を許可してください。補助ツールの対象はメインユーザー（ユーザー0）です。

1. 新版のAPKをインストールします。旧版もインストールしたままにします。
2. このリポジトリのソースから、次を実行します。`端末ID`には`adb devices`の接続先を指定し、バックアップ先にはまだ存在しない専用フォルダを指定します。

   ```sh
   python3 tools/migrate_settings.py --serial 端末ID --backup-dir /安全な場所/DarkAppTools移行前
   ```

   Android SDKが標準の場所にない場合は`ANDROID_HOME`、または`--adb`・`--apksigner`を指定してください。

3. 移行成功の表示を確認し、新版の設定画面で有効状態・テーマ・言語が一致することを確認します。
4. Vectorで旧IDを無効化し、新IDを有効化します。新IDの対象にセサミ・povoが表示されることを確認します。
5. 対象アプリを強制停止して開き直し、新版の「モジュールの状態」を確認します。
6. 問題がなければ旧IDだけを削除します。

   ```sh
   adb -s 端末ID uninstall dev.ryuya.sesameui
   ```

ツールは両アプリの署名を確認し、元の設定をバックアップしてから移行結果を照合します。既に新版で設定が保存されている場合は上書きせず停止します。旧アプリの削除、モジュールの有効化、端末・SystemUIの再起動は行いません。

## 手動で移す場合

旧版でセサミ・povoそれぞれの有効状態とテーマ、アプリの言語を控え、新版で同じ設定にします。その後、上記の4〜6を行います。元のセサミ・povoアプリをアンインストールする必要はありません。
